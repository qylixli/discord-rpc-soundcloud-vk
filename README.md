# Discord RPC для SoundCloud и VK Музыки

Показывает в вашем Discord, что вы сейчас слушаете **на сайте** SoundCloud или VK Музыки: название, исполнитель,
обложка и полоса времени («прошло / конец»). Поставили на паузу или закрыли вкладку, и статус пропадает сам.

[English version → README.en.md](README.en.md)

> Что получится: в профиле Discord появится «Слушает: исполнитель», а под ним трек, обложка и бегущее время.
> Работает с сайтами в браузере, отдельное приложение SoundCloud или VK ставить не нужно.

| Сервис | Статус |
|---|---|
| SoundCloud (soundcloud.com) | работает |
| VK Музыка (vk.com) | работает |

---

## Что нужно

- **Windows 10 или 11** (установщик и автозапуск сделаны для Windows; на Linux/macOS запускается вручную, см. внизу)
- **Приложение Discord на компьютере** (не вкладка в браузере)
- **[Node.js](https://nodejs.org)** версии 18 или новее (скачайте «LTS»)
- Браузер с расширением **[Tampermonkey](https://www.tampermonkey.net/)** (Firefox, Chrome, Edge и др.)

## Быстрый старт

### 1. Создайте приложение в Discord (1 минута)

Оно нужно, чтобы статус показывался от вашего имени. Это бесплатно и безопасно.

1. Откройте https://discord.com/developers/applications и нажмите **New Application**.
2. Назовите как угодно (например, `Музыка`) и создайте.
3. На вкладке **General Information** скопируйте **Application ID** (17–20 цифр). Он понадобится на шаге 3.

### 2. Скачайте проект

Нажмите на GitHub зелёную кнопку **Code → Download ZIP** и распакуйте архив в постоянное место без пробелов и
спецсимволов в пути, например `C:\discord-rpc`. Потом папку не переносите.

### 3. Запустите установщик

Дважды щёлкните **`install.bat`**. Он:
- проверит Node.js и скачает нужные библиотеки,
- спросит ваш **Application ID** (вставьте из шага 1),
- добавит программу в автозапуск (она будет работать **в фоне, без окна**, при каждом входе в Windows),
- сразу запустит её.

### 4. Поставьте скрипты в Tampermonkey

В папке `userscripts` лежат два файла. Поставьте нужные (можно оба):
- `soundcloud.user.js` для SoundCloud
- `vk.user.js` для VK Музыки

Как поставить: откройте файл на GitHub, нажмите кнопку **Raw**, и Tampermonkey сам предложит установку, нажмите
**Установить**. Если не предложил: Tampermonkey → **Создать скрипт** → сотрите содержимое → вставьте весь текст файла →
**Файл → Сохранить**.

При первом запуске Tampermonkey может спросить разрешение на доступ к `127.0.0.1`, выберите **«Всегда разрешать»**.
(Это ваш собственный компьютер, туда скрипт и отправляет данные.)

### 5. Включите статус активности в Discord

**Настройки → Конфиденциальность активности (Activity Privacy)** → включите показ статуса активности.

### 6. Слушайте

Откройте soundcloud.com или vk.com, включите трек, и через пару секунд статус появится в Discord. Больше ничего
нажимать не нужно: после перезагрузки компьютера программа стартует сама.

## Настройки

Файл `companion\config.json` (создаётся установщиком). После изменений перезапустите программу (`install.bat` ещё раз).

| Поле | Значения | Что делает |
|---|---|---|
| `clientId` | Application ID | обязательно |
| `statusDisplay` | `"artist"` (по умолчанию) / `"app"` | что в заголовке статуса: имя исполнителя или название сервиса |
| `showButton` | `false` (по умолчанию) / `true` | кнопка «Listen on …» со ссылкой на трек (другие её видят, у себя в профиле нет) |

Если играют сразу SoundCloud и VK, показывается тот, что запущен позже. Когда его ставят на паузу, возвращается первый.

## Если не работает

Сначала посмотрите, что пишет программа: файл **`companion.log`** в папке проекта (появляется после запуска).

| Что видно | Что делать |
|---|---|
| `Не удалось подключиться к Discord` | Запустите приложение Discord на компьютере (не сайт) и подождите несколько секунд, подключение повторяется само. |
| `Cannot find module '@xhayper/discord-rpc'` | Не скачались зависимости. Откройте cmd в папке `companion` и выполните `npm install`, затем запустите `install.bat` ещё раз. |
| В логе нет строки `Играет: …` | Данные не доходят от браузера. Проверьте, что скрипт включён в Tampermonkey и что вы разрешили доступ к `127.0.0.1`. |
| `Играет: …` есть, а в Discord пусто | Проверьте шаг 5 и что `clientId` в `config.json` правильный. |
| При запуске Windows окно «Windows Script Host: Can not find script file» | Это старый автозапуск (он ломался на путях с русскими буквами). Запустите `install.bat` ещё раз: он удалит старый автозапуск и создаст правильный. |
| Порт 47612 занят | Программа уже запущена. Закройте лишнюю копию (`uninstall.bat`, потом `install.bat`). |
| Нет обложки, неверное время | Сайт мог изменить вёрстку, откройте [Issue](../../issues). |

**VK не показывается?** Откройте vk.com, нажмите `F12` → вкладка **Консоль** и найдите строки `[VK→Discord]`. Они пишут
«играет», «не играет» или «плеер VK не найден». Приложите это к Issue.

## Удаление

Запустите **`uninstall.bat`** (остановит программу и уберёт автозапуск), затем удалите папку и скрипты в Tampermonkey.

## Приватность и безопасность

- Скрипты отправляют название, исполнителя, ссылки на обложку и трек и время **только на `127.0.0.1`**, то есть на ваш же
  компьютер. Больше никуда.
- Программа слушает только `127.0.0.1`, принимает данные лишь от страниц SoundCloud и VK (проверяются `Origin`,
  `Host` и особый заголовок), отвергает остальное, а ссылки пропускает только на домены этих сервисов.
- Единственный, кто получает информацию о треке, это Discord (так работает статус активности).
- Код небольшой и открытый, его можно прочитать: `companion/` (программа) и `userscripts/` (скрипты).

## Как это устроено

```
Браузер (Tampermonkey-скрипт читает плеер на странице)
        │  раз в секунду, только на 127.0.0.1:47612
        ▼
Программа (Node.js, в фоне) ──► приложение Discord на вашем ПК ──► ваш статус
```

Программа сама решает, когда обновлять статус (смена трека, пауза, перемотка), чтобы не упираться в лимиты Discord.

## Linux и macOS

Установщика нет, но всё остальное работает. Установите Node.js 18+, затем:

```
cd companion
npm install
cp config.example.json config.json   # впишите свой Application ID
node index.js
```

Скрипты ставятся в Tampermonkey так же. Автозапуск настройте средствами системы (systemd/launchd).

## Разработка

```
cd companion
npm test
```

Тесты не требуют ни Discord, ни браузера.
